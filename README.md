# Rudrax – Multilingual Language Translator

Rudrax is a web-based language translation application designed to make communication across different languages simple and accessible. Built using HTML, CSS, JavaScript, and Tailwind CSS, it provides an easy-to-use interface for translating text using the MyMemory Translation API.

## Key Features

- **Multilingual Translation:** Supports 18 languages, including English, Hindi, Spanish, French, German, Chinese, Japanese, and more.
- **Automatic Language Detection:** Automatically identifies the source language when supported by the translation service.
- **Text-to-Speech:** Allows users to listen to original and translated text using browser speech synthesis.
- **Language Swapping:** Quickly switches between source and target languages.
- **Copy Translation:** Copies translated text to the clipboard with one click.
- **Dark and Light Mode:** Provides a customizable viewing experience.
- **Responsive Design:** Designed for desktop, tablet, and mobile screens.
- **Character Counter:** Supports text input up to 5,000 characters.
- **Error Handling:** Displays helpful messages when translation requests fail.

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Tailwind CSS
- MyMemory Translation API
- Web Speech API

## How It Works

1. Enter the text you want to translate.
2. Select the source language or enable automatic detection.
3. Choose the target language.
4. Click the Translate button.
5. View, listen to, or copy the translated result.

## Project Objective

The objective of Rudrax is to develop a simple and accessible translation tool that helps users overcome language barriers through a clean interface and useful language-processing features.
